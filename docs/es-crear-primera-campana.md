# Crear primera campana

## Mejor forma de empezar

Usa el chat como si hablaras con un manager de performance:

```text
Crea una campana para vender mi asesoría de nutricion con $15 diarios, para mujeres en Medellin, enviando a https://miweb.com.
```

El agente debe pedir una sola cosa a la vez si falta informacion.

## Informacion que puede pedir

- Producto u oferta.
- Publico o ubicacion.
- Presupuesto diario.
- URL de destino.
- Angulo creativo.
- Imagen o asset creativo.
- Si quieres dejarla pausada o activa despues de aprobar.

## Campanas listas para gastar

La campaña se crea primero en pausa. Cuando decidas activarla, la aprobación debe decir claramente que puede gastar dinero y pedir esta confirmación:

```text
Si, activar
```

Puedes confirmar desde el chat con esa frase o usar el botón exacto en Telegram; el identificador técnico permanece oculto.
