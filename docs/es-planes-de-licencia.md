# Planes de licencia

## Licencia Individual

Pensada para una persona que administra su propio negocio.

- Instalación en 1 dispositivo.
- 1 cuenta publicitaria de Meta activa.
- 1 página de Facebook activa.
- Telegram para ese negocio, si desea conectarlo.
- Puede cambiar de negocio más adelante, pero el agente elimina la memoria, métricas, historial y guías creativas anteriores para empezar limpio.

Esta regla evita mezclar información de dos negocios y mantiene la licencia adecuada para uso propio.

## Licencia Agencia

Pensada para quien ofrece el servicio a varios negocios.

- Pago único sugerido: USD 200.
- Instalación en hasta 4 dispositivos.
- Espacios separados para múltiples clientes.
- Cada espacio conserva su conexión local a Meta, cuenta publicitaria, página, memoria del agente y configuración de Telegram.
- Al abrir un cliente, el agente de Telegram de ese espacio queda activo. Esto evita responder con datos del cliente equivocado.
- Permite alternar entre clientes sin perder la información de cada uno.

## Qué significa un espacio de cliente

Un espacio mantiene separado:

- El negocio y su estrategia inicial.
- El token de Meta guardado localmente para ese cliente.
- La cuenta de anuncios y página elegidas.
- Métricas y lectura diaria.
- Conversación con el agente.
- Actividad y aprobaciones.
- Conexión de Telegram configurada para ese cliente, activa mientras ese espacio está abierto.

Así una agencia puede trabajar con varios clientes sin mezclar decisiones ni reportes.

Las conexiones privadas de cada espacio se guardan solamente en el PC/VPS del comprador con permisos restringidos al usuario que ejecuta el producto. No se envían al vendedor.
