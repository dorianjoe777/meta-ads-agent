# Checklist antes de dejar anuncios activos

Antes de aprobar una campana activa, confirma:

- Licencia activa.
- Dashboard desbloqueado.
- Datos reales de Meta visibles.
- Cuenta publicitaria correcta.
- Pagina de Facebook correcta.
- URL de destino correcta.
- Presupuesto diario correcto.
- Creativo correcto.
- La tarjeta dice `ACTIVE` y entiendes que puede gastar dinero.
- Confirmaste `Si, activar`.

Si tienes duda, crea primero en pausa y revisa todo dentro de Meta Ads Manager.
