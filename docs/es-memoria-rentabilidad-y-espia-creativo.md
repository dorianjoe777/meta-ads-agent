# Memoria de rentabilidad y Espia Creativo

Este archivo queda como indice porque son dos piezas conectadas, pero no son la misma funcion.

- [Memoria de rentabilidad](es-memoria-de-rentabilidad.md): el cerebro operativo del agente. Guarda reglas, decisiones, acciones y resultados para no volver a empezar desde cero.
- [Espia Creativo](es-espia-creativo.md): el modulo de investigacion creativa. Analiza anuncios fuertes, extrae patrones y ayuda a crear versiones originales para la marca del comprador.
- [Filosofia action-first](es-filosofia-action-first.md): como traducimos la referencia de BigPlayers en producto: menos reporte pasivo, mas decisiones preparadas y acciones bajo reglas.

La relacion correcta es:

1. La memoria de rentabilidad decide que necesita el negocio.
2. Espia Creativo encuentra y transforma ideas cuando el problema es de creatividad.
3. El agente ejecuta o prepara la accion segun el nivel de control del comprador.
