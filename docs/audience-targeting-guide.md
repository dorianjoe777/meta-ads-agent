# Guía de audiencias y lookalikes

Esta versión recomienda audiencias, pero no sube listas de clientes automáticamente.

## Qué puede hacer el agente

- Recomendar una campaña amplia / Advantage+.
- Proponer una prueba por intereses cuando el nicho es claro.
- Separar retargeting si ya hay pixel, leads, visitas o engagement.
- Revisar si tiene sentido crear lookalikes.
- Avisar si faltan datos o consentimiento.

## Cuándo usar lookalikes

Un lookalike necesita una audiencia semilla. Puede venir de:

- Compradores o leads con consentimiento.
- Eventos del pixel o Conversion API.
- Engagement de Instagram/Facebook.
- Audiencias personalizadas ya existentes.

Para v1, el flujo correcto es recomendar y revisar. La subida automática de emails o teléfonos debe esperar a tener un flujo claro de consentimiento, privacidad y aprobación.

## Recomendación para compradores nuevos

Empieza simple:

1. Campaña amplia / Advantage+.
2. Una campaña de intereses si el mercado es específico.
3. Retargeting separado si ya hay tráfico.
4. Lookalike solo cuando exista una fuente semilla confiable.

El objetivo es evitar que una persona principiante se bloquee con términos técnicos o suba datos sensibles sin entender qué está haciendo.
