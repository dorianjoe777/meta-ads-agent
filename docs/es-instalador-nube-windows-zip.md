# Instalador para clientes Windows (ZIP)

Este paquete no contiene un ejecutable `.exe`, por lo que evita el bloqueo de reputación de Chrome para binarios nuevos sin firma.

1. Descarga y extrae el ZIP.
2. Haz doble clic en `Instalar Admira IA en la nube.vbs`.
3. Se abrirá directamente la interfaz gráfica de instalación, sin terminal.

La interfaz solicita correo de compra, licencia, token de DigitalOcean, región y tamaño del Droplet. Al terminar crea el acceso directo y abre el onboarding.
