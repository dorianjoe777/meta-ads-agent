# Filosofia action-first

La referencia de BigPlayers no vende un dashboard de reportes. Vende un cambio de relacion con Ads Manager:

> De preguntar que pasa, a tener un manager que mira, decide y actua bajo reglas.

La frase central del post es "from asking to acting". Nuestro producto tiene que sentirse asi.

## Lo que vimos en la referencia

El post muestra cuatro ideas importantes:

1. **La notificacion heroica es una accion**, no un grafico: "Bleeder paused. Saved $120."
2. **El brief de la manana separa lo ejecutado de lo pendiente**:
   - pausado automatico
   - escalado necesita aprobacion
   - algo para vigilar
   - datos del dia
   - pruebas siguientes
3. **La arquitectura no termina en reporte**: agente -> skills -> Meta Graph API -> datos + decisiones + acciones -> Telegram.
4. **La parte creativa cierra el loop**: datos dicen que gana; el sistema creativo ayuda a producir mas versiones.

## Como debe funcionar Admira IA

Cada lectura diaria debe terminar con accion, aunque la accion sea "dejar preparado para aprobar".

Tres grupos claros:

- **Ya hice**: acciones seguras sin gasto, por ejemplo preparar una estructura en pausa o generar nuevos borradores creativos.
- **Necesita tu luz verde**: presupuesto, reactivaciones, campanas nuevas activas, uploads creativos o cualquier cambio fuera de limites.
- **Estoy vigilando**: senales tempranas donde aun no conviene tocar nada.

Esto evita que el producto se vuelva un dashboard bonito que solo explica.

## Aprobaciones no son el producto

Las aprobaciones son una capa de confianza, no la experiencia principal.

La experiencia principal es:

1. el agente detecta
2. el agente decide
3. el agente prepara o ejecuta
4. el comprador responde rapido
5. el agente recuerda el resultado

La regla es unica: el agente puede preparar y crear estructuras en pausa cuando el comprador ya lo pidio; activar, gastar, publicar visible, borrar, enviar datos sensibles o cambiar una campaña viva requiere luz verde clara.

## Que acciones deben ser mas automaticas

Acciones que pueden avanzar sin friccion cuando no gastan ni cambian campañas vivas:

- generar borradores creativos por fatiga
- actualizar lectura diaria
- crear reportes
- guardar aprendizajes

Acciones que deben pedir aprobacion por defecto:

- subir presupuesto
- mover presupuesto grande
- reactivar campanas
- crear campanas activas
- subir creativos a Meta
- cambiar reglas de rentabilidad

Esto coincide mejor con el espiritu del post: auto-pausar sangrado claro, pedir aprobacion para escalar o tocar dinero de forma mas agresiva.

## Copy recomendado

No decir:

> Mira tus metricas en un dashboard.

Decir:

> Tu manager IA despierta, revisa la cuenta, frena lo que esta sangrando, te prepara el siguiente movimiento y te pide luz verde cuando toca dinero real.

No decir:

> Genera reportes.

Decir:

> Cada manana recibes lo que ya hizo, lo que necesita tu aprobacion y lo que esta vigilando.

No decir:

> Inspiracion creativa.

Decir:

> Espia la estrategia de anuncios fuertes y crea tu version original.
